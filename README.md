# 雨の森 · Totoro Rain

一个以《龙猫》雨夜公交站为灵感的实时 Web 3D 场景。使用 Three.js 与 Vite，角色、植物、雨伞、车站与纹理均由代码生成，无需下载外部模型。

## 本地运行

```sh
npm install
npm run dev
```

## 生产构建

```sh
npm run build
npm run preview
```

## 操作

- 开启电影之旅：三个镜头每 16 秒自动转换，缓慢推进与环绕。
- 底部镜头卡：切换到特定构图。
- 拖动画面旋转，滚轮或双指缩放；拖动会退出自动运镜。
- 右侧「返回」或 Escape：恢复首页构图。
- 雨声：用户点击后以 Web Audio 合成环境雨声。
- 氛围：调整雨量、曝光或恢复默认值。
- 全屏：沉浸式桌面体验。

支持窄屏布局与系统减少动态效果偏好。环境音默认关闭；切换后台时暂停场景更新。Google Fonts 不可用时自动使用系统中文字体。需要支持 WebGL 2 的现代浏览器。

独立粉丝创作，非吉卜力官方项目。角色与经典场景以程序化造型重新演绎。
